# Ambit Data Studio

Portal interno de análisis operativo. Esta primera versión contiene únicamente
la estructura visual y técnica del portal; los módulos todavía no están desarrollados.

## Visualización local

Abre una terminal en la carpeta del proyecto y ejecuta:

```powershell
python -m http.server 8000
```

Después visita `http://localhost:8000` en el navegador. Para detener el servidor,
presiona `Ctrl+C` en la terminal.

No se requieren instalaciones, bases de datos ni servicios externos.
