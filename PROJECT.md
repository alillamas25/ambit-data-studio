## Estructura base del portal

Estado: Primera versión completada

La página inicial establece el portal interno Ambit Data Studio con HTML, CSS y
JavaScript sin frameworks. Presenta directamente un catálogo compacto de
herramientas en definición, sin lógica de análisis ni conexiones externas. La
identidad utiliza el logo oficial proporcionado como recurso local y colores de
interfaz centralizados en variables CSS.

Organización actual:

- `index.html`: estructura de la página inicial.
- `css/`: estilos base, de composición y de componentes.
- `js/app.js`: punto de entrada de JavaScript.
- `js/modules/`: componentes independientes del catálogo del portal.
- `assets/`: recursos visuales locales.

Los módulos Restaurant Billing y Analizador Inteligente de Órdenes no están
desarrollados; solo aparecen como espacios informativos dentro del portal.
